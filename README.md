A free, open way to get past Zoom Error 1132 on Windows. It runs Zoom inside a separate, standard Windows account, so Zoom starts completely fresh. The app runs entirely on your own computer, so only Zoom itself connects to the internet.

How to use it

	1.	Download the zip from the latest release (under Assets).
	2.	Right-click the zip > Properties. Check Unblock, then click OK. (No Unblock box? Skip this step.)
	3.	Right-click the zip > Extract All > Extract.
	4.	In the folder that opens, double-click The People's 1132 Fix. (A black window may flash for a second the first time. That's normal.)
	5.	Click Set up, then click Yes when Windows asks for permission.
	6.	When it says "All set," click Open Zoom.

After the first time, you'll have two icons on your desktop: The People's 1132 Fix opens the app, and The People's Zoom opens the fresh Zoom directly.

Full instructions are in README.txt inside the zip.

Why it's safer

	•	No automatic updates. The file you download is the file that runs, every time. Nobody can change it on your PC from a server.
	•	No tracking. The app never sends anything about you or your PC anywhere. (Zoom still uses the internet as normal.)
	•	The helper account is a standard user, never an administrator.
	•	It's plain text. Open the App files folder and read every line in Notepad.

Don't take our word for it

	•	Check your download. Each release lists a SHA-256 checksum. Open PowerShell in your Downloads folder, run Get-FileHash followed by the zip's name, and make sure the result matches.
	•	Ask your own AI. Attach Peoples1132Fix.ps1 (in the App files folder) and the two .cmd files to Claude or ChatGPT, and ask it to review every line for anything that connects to the internet, hides what it does, or gives anyone access to your PC.
	•	About VirusTotal. Security vendors show 0 detections. VirusTotal also lists "behavior" flags, such as creating a local user and hiding a PowerShell window. Those describe exactly what the app is built to do.

Only download it here

Good to know
