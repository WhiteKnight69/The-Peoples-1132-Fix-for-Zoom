# Security Policy

## Supported Versions

Only the most recent release gets security fixes. Always use the latest version from the [Releases page](https://github.com/WhiteKnight69/The-People-s-1132-Fix-for-Zoom/releases/latest).

| Version          | Supported          |
| ---------------- | ------------------ |
| 2.9 (latest)     | :white_check_mark: |
| Earlier versions | :x:                |

## Reporting a Vulnerability

Before you report: this app is plain text and runs entirely on your own computer, with no server and no automatic updates. You can confirm your copy is genuine by checking its SHA-256 checksum against the one listed on the release (run `Get-FileHash` in your Downloads folder), and you can read every line yourself in the `App files` folder.

If you find something you believe is a security problem:

- **Not sensitive** (a question, or something that just looks off): open an issue at https://github.com/WhiteKnight69/The-People-s-1132-Fix-for-Zoom/issues
- **Sensitive**: use GitHub's private vulnerability reporting on this repository (the **Security** tab, then **Report a vulnerability**). That keeps the details private until it is resolved.

Please include the version you downloaded, your Windows version, and clear steps for what you saw.

What to expect:

- An initial reply within about 3 to 5 days.
- Updates as there is news, and at least every week or two while the report is open.
- If it is confirmed, a fix in a new release, a note in that release describing what changed, and credit to you if you want it.
- If it is declined, a plain explanation of why it is not considered a security issue.

Getting around a Zoom block is against Zoom's terms of service. Use it at your own risk.
